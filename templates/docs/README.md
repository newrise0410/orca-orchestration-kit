## 1. 문서 관리 규칙

### 1.1 폴더 번호
| 폴더 | 내용 |
|---|---|
{{DOC_FOLDERS_TABLE}}

폴더 이름은 `<번호 2자리>_<이름>`이다. 번호는 진행 순서를 따른다. 새 단계 폴더가 생기면 다음 빈 번호를 붙인다. `05`~`07`은 단계와 무관하게 고정이다.

### 1.2 문서 파일명
```
<순번 2자리>_<문서명>_<YYYYMMDD>.md
예) 01_요구사항추적표_{{TODAY_COMPACT}}.md
```
- **순번**: 폴더 안에서 작성 순서대로 붙인다. 한 번 붙인 순번은 바꾸지 않고, 폐기한 문서의 순번은 다시 쓰지 않는다.
- **문서명**: 한글을 허용하고 띄어쓰기는 쓰지 않는다. 단어 구분은 `-`.
- **날짜**: 그 판(版)의 작성·개정일이다. 개정하면 `git mv`로 날짜를 바꾸고 문서 안 개정이력 표에 기록한다.
- 다른 문서에서 참조할 때는 날짜를 와일드카드로 쓴다. 예: `docs/{{REQ_FOLDER}}/01_요구사항추적표_*.md`. 개정해도 참조가 깨지지 않는다.
- **보관 사본**: 이전 판을 파일로 남겨야 하면 `<순번>_<문서명>_v<판>_<YYYYMMDD>.md`로 둔다. 순번은 원본과 같고, 문서 목록에는 원본만 올린다.
- 예외: `06_evidence/`는 작업 ID 폴더 구조(`<작업ID>/report.md`)를 쓴다. 폴더 안내 `README.md`는 번호를 붙이지 않는다. `07_process/snapshots/`는 대시보드 스냅샷 보관용이다.
